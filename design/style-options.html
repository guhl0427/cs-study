方向 A

蓝图制图 Blueprint · Engineering Drawing

立意：计算机是工程学科，路线图本质是一张「施工图」。整个界面 = 绘图桌上的网格图纸：细网格纸底、线稿式卡片（直角 + 投影偏移）、图纸标题栏、剖面线填充的难度图例、虚线表达的依赖关系。

契合：①「学习地图」字面成立——每一页都像一张图；②依赖连线、阶段划分与工程制图语言天然同构；③浅色底 + 墨蓝，长文阅读舒适；④等宽字标注时长/编号，信息密度友好。

注意：直角 + 线稿偏严肃，温度感低于 C；圆角体系极小，组件细节要靠线宽与剖面线撑起来。

方向 B

编辑器语法 Syntax · IDE Light

立意：这个平台一半的页面是代码，那就让 UI 从「编辑器语法高亮」借一整套语义色：每个 UI 语义（领域/难度/状态）对应一个语法 token 色，卡片头像用代码符号，课程卡片头部做成编辑器标签页，代码块天然就是深色编辑器。

契合：①对 CS 用户零解释成本——一眼就是「自己人」的工具；②知识点页（正文 + 代码块）的阅读体验最顺；③语义色系统可直接映射到 Tailwind token；④未来深色主题 = 换一套编辑器主题，成本极低。

注意：工具感强、情感温度中等；需要克制使用语义色，避免全页「圣诞树」。

方向 C

地图册暖纸 Atlas · Field Notes

立意：把「学习地图」彻底字面化——产品是一本旅行图册：领域 = 地域，路线 = 徒步路径，打卡 = 行程印章，连续学习天数 = 旅程足迹。宋体标题 + 暖纸底 + 经纬细线，传达「有人陪你把这条路走完」的陪伴感。

方向 D

星图夜航 Starchart · Night Study

立意：夜晚是自学者真正打开电脑的时间。每个领域是一座星座，知识点是星，依赖关系是星座连线——学完一颗就点亮一颗。深空蓝黑 + 星光白 + 流星金，成就感的视觉化达到最大化。

契合：①「点亮知识星座」把 F2 路线图和 F4 进度变成同一个强隐喻；②深色长时间盯屏友好，夜间学习场景贴合学生作息；③路线图页面可以做出全站最有记忆点的一屏。

注意：深色为主时正文长文要控制对比度（星白非纯白）；表格/表单/打印场景需额外校对；若要浅色模式等于双主题成本。
