# 12 · 错题本 `/mistakes`

> 功能 F5.3 · P1 · 组件：MistakeList / FilterTabs / QuizCard(重做复用) / EmptyState / StorageNotice
> 数据源：`cs-study:answers` 中 `isCorrect=false` 的记录，按知识点归类聚合。

## 目的

把「错过的题」变成「复习清单」：按知识点归类、支持重做、与导出迁移打通。

## 布局（container-wide，单列内容）

```
┌──────────────────────────────────────────────────────────────────┐
│ AppHeader                                                         │
├──────────────────────────────────────────────────────────────────┤
│ PageHeader：错题本 (h1) + 副文案「答错的题都在这里，重做对了就移出」   │
│                                                                  │
│ ① 过滤行：[全部 | 未重做 | 已重做] · 领域 Tab（可选）               │
│    统计 mono：共 {n} 题 · 未重做 {m} 题                            │
│                                                                  │
│ ② 按知识点分组列表                                                 │
│ ┌ 第 2 章 · Promise 与异步编程（{3} 题）[重做本组] ┐                │
│ │ ┌────────────────────────────────────────────┐ │                │
│ │ │ ✕ {题干截断两行}           状态:未重做        │ │                │
│ │ │   上次作答 2026-11-19 · [重做]               │ │                │
│ │ └────────────────────────────────────────────┘ │                │
│ │ （同组条目…）                                    │                │
│ └────────────────────────────────────────────────┘                │
│   …（其他知识点分组…）                                              │
│                                                                  │
│ AppFooter                                                         │
└──────────────────────────────────────────────────────────────────┘
```

## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |
| ---- | ---- | ---- | ---- |
| ① | 过滤行 | 状态 Tab（全部/未重做/已重做）+ 领域 Tab；统计行 mono | 即时过滤（本地数据） |
| ② | 分组列表 | 组头：知识点名 + 该组题数 + [重做本组]；条目：题干（≤2 行截断）+ 上次作答时间 + 状态 Chip + [重做] | 重做 → /quiz/:id（仅错题子集）；答对 → 条目状态变「已重做」，不再计入薄弱提示 |
| — | 空状态 | EmptyState：「错题本是空的——去完成一次练习，答错的题会自动出现在这里」+ [去看课程练习] | 无作答记录时 |

## 边界

- 孤儿记录（知识点已下架）静默忽略并在下次导出清理（需求 §7.2 设计要点 3）——UI 不显示失效条目。
- `answers` FIFO 500 条上限触顶时，本页顶部 mono 弱提示「作答记录已达上限，最早的记录将被滚动清除」。

## 验收要点

- [ ] 重做答对后条目状态即时更新（本地写）
- [ ] 分组按「知识点归类」（F5.3），组内按作答时间倒序
- [ ] 随导出/导入迁移（与 F5 说明 3 一致）
