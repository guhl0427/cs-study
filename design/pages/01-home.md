# 01 · 首页 `/`

> 功能 F1 · P0 · 组件：AppHeader / PageHeader(图纸标题栏变体) / ContinueCard / DomainCard / QuickStartEntry / FeaturedStrip / GridPaper
> 页面唯一 `h1` = 产品主标题；页面目标 = 需求 §1.3「新用户 3 分钟内进入领域/路线页 ≥ 40%」

## 目的

打开就能学：3 分钟内让访客完成「知道有哪些方向 → 选定一个入口」。首屏必须同时回答「这是什么平台」和「我从哪开始」。

## 首屏两种形态（F1.5，同一区块位二选一）

| 形态 | 判定 | Hero 右卡内容 |
| ---- | ---- | ---- |
| 回访 | 本地存在 `progress`/`lastVisit` | **ContinueCard**：上次学到 → 继续学习（学习闭环入口优先） |
| 新访客 | 无任何本地记录 | **找方向引导卡**：「不确定从哪开始？3 道题为你推荐路线」+ [开始找方向] + 次链接「先随便看看 →」 |

两种形态的 Hero 左侧文案一致；「3 分钟找到方向」主按钮永远存在（指向 /guide）。

## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |
| ---- | ---- | ---- | ---- |
| ① | Hero（GridPaper） | h1 + 副文案 + 双 CTA + ContinueCard/引导卡 + 图纸标题栏 | 标题栏为静态元数据（领域数、版本取构建期数据）；CTA 主=accent 实底 |
| ② | 领域卡片墙 | 9 张 DomainCard（icon/名称/一句话/课程数/路线数/难度跨度），按 §3.2 领域顺序 | 整卡点击 → /domain/:slug；hover 投影加深；无加载态（构建期数据随路由即出） |
| ③ | 新手快捷入口 | 预设入口「零基础从这里开始 / CS 学生补强路线 / 转行求快」→ 对应 /path/:slug | 点击写 `activePathId` 并 Toast「已设为当前路线」，再跳转 |
| ④ | 编辑精选 | 静态配置推荐位（课程/路线），含每周时长、周期 | [查看路线] → /path/:slug；无数据时整块不渲染 |

## 响应式

- `<640`：Hero 单列（卡在文案下方）；卡片墙 1 列；快捷入口纵向堆叠；图纸标题栏 2×2。
- `640–1023`：卡片墙 2 列；Hero 保持双列（卡最小宽 280px）。

## 空状态与降级

- 内容 JSON 缺领域 → 卡片墙渲染 0 张时显示 EmptyState「内容筹备中」+ 找方向入口（理论上构建期校验会拦截）。
- 存储不可用 → AppHeader 下全局警示条（见 components.md StorageNotice），首页其余不变。

## 验收要点

- [ ] 新访客首屏即见「这是什么 + 从哪开始」两个答案；CTA 不低于 44px 高
- [ ] 回访用户首屏可见「继续学习」（可用性测试指标 F1.5 ≥50% 使用率的载体）
- [ ] 9 张领域卡信息结构一致；难度跨度徽标全部可读（AA）
- [ ] 无自动轮播、无入场动画（原则 6）
- [ ] 375px 宽无横向滚动
