# 07 · 知识点内容页 `/course/:slug/lesson/:lessonSlug`

> 功能 F3.3 / F3.4 / F3.5 / F3.6 / F4.1 · P0 · SEO 主战场（每页唯一 h1、meta 由 frontmatter 生成）
> 组件：LessonArticle / CodeBlock / ExternalResourceCard / TocPanel / PrevNextNav / MarkDoneButton / FeedbackLink / StorageNotice / LastUpdated

## 目的

内容的最小学习单元：一页读完 → 一次「标记完成」→ 回到路线图看见点亮。SEO 与可读性双优先。

## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |
| ---- | ---- | ---- | ---- |
| ① | 课程目录（左粘性栏） | 本课程章节 → 知识点树；当前项 accent 短线；已完成 ✓ | 点击切换路由；`<1024` 折叠为正文顶部「本课程目录」details 块 |
| ② | 正文 | 六段式固定结构（需求 §3.4）：一句话定义 → 概念讲解 → 代码示例 → 常见坑 → 小练习 → 精选外链；标题层级 h1(页) / h2(段) / h3(小节) | CodeBlock 一键复制（F3.5）；图允许渲染（构建期白名单，防 XSS 为红线） |
| ③ | 右辅助列 | TocPanel（h2/h3 锚点，滚动联动高亮）+ FeedbackLink（⚑ 报错/建议，F3.6） | Issue 预填模板含页面路径 + Git SHA；仓库不可用降级为复制模板 |

| ⑤ | 存储提示行 | StorageNotice 弱形态：一行 caption + 「导出备份」链接 → /settings | 常驻不隐藏（原则 5） |

## 交互细节

- **滚动联动**：TocPanel 高亮与正文小节双向同步；粘性列各自独立滚动（`position: sticky`）。
- **「标记完成链」**（唯一编排动效）：按钮打勾 120ms → 进度条增长 200ms（下一访问课程页可见）→ 路线图节点点亮 320ms（下次访问路线图可见；本页内仅按钮与 Toast「已记录：{知识点名}」）。
- **游客态（隐私模式）**：可点「标记完成」，但全局警示条在场；点击后 Toast 提示「游客试用：刷新后丢失」。
- **外链统一出口**：ExternalResourceCard 是本页唯一外链形态，`rel="noopener noreferrer"` 强制。

## 响应式

- `<1024`：单列 = 面包屑 → 目录折叠块 → 正文 → 底部动作条 → 提示行；TocPanel 隐藏（用 details 折叠目录替代）。
- 底部动作条在移动端为 sticky 底栏（安全区适配），MarkDoneButton 全宽。

## 空状态

- 正文渲染失败（构建期已编译，理论不出现）→ 错误占位块 + FeedbackLink。
- 无精选外链 → 该小节渲染 EmptyState 弱形态一行「本知识点外链资源筹备中」+ 报错入口。

## 验收要点

- [ ] h1 唯一 = 知识点名；title/meta 描述来自 frontmatter（SEO ≥95 的载体）
- [ ] 六段式结构完整渲染；代码块可复制且 Shiki 主题 = blueprint-draft
- [ ] 「标记完成」即写本地、回访保持；取消完成同样即时
- [ ] 本页存在常驻「仅存本设备」提示（原则 5）
- [ ] 正文列宽 ≤720px、行长 40–45 字；375px 无横向滚动（代码块横向滚动不撑破页面）
