# 09 · 数据管理 `/settings`

> 功能 F7（7.4–7.6）· P0 · 组件：ExportCard / ImportCard / ClearDataCard / ConfirmDialog / StorageNotice(常驻) / Toast
> 导出文件 = 本产品的「账号」（F7 定位），本页文案要传递这个定位，但不用「账号」一词制造误导（F10 风险：不出现「云同步」）。

## 目的

备份、迁移、清空三件事的单一入口；所有破坏性操作有明确后果说明与二次确认。

## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |
| ---- | ---- | ---- | ---- |
| ① | 概览卡 | 存储用量（实时统计各 key 尺寸）/ 分类条数 / 上次导出时间（`lastExportAt` 存本地） | 用量 ≥ 800KB 时 `--warning` 提示「接近配额，建议清理作答记录」 |
| ② | ExportCard | 导出 `{app, schemaVersion, exportedAt, data}` JSON | 成功 → Toast「已导出，共 {n} 条记录」+ 更新上次导出时间 |
| ③ | ImportCard | 文件选择（.json 校验 app 名与 schemaVersion）→ 策略单选 → 执行 | 旧版本文件先经迁移器升级（F7.3）；**覆盖**必须 ConfirmDialog：「导入文件将完全替换本机 {n} 条数据，此操作不可恢复」；成功 → Toast 统计「新增 x · 更新 y · 跳过 z」 |
| ④ | ClearDataCard | danger 描边卡；按钮 `--danger` 描边、点击后实底 | ConfirmDialog 二次确认（标题「清空本机全部学习数据」+ 不可恢复说明 + 建议先导出）；成功 → 回游客态并跳首页 |
| ⑤ | 常驻提示条 | StorageNotice 常驻强度 | — |

## 异常与边界

| 场景 | 行为 |
| ---- | ---- |
| 导入文件格式不符 | 行内错误：「这不是 cs-study 导出文件（缺少标识字段）」，不执行 |
| 导入文件 schemaVersion 高于当前 | 行内错误：「文件来自更新版本，请先升级应用」，不执行 |
| 存储不可用 | 导出仍可用（下载不依赖存储）；导入执行后 Toast 警示「进度无法保存」；全局警示条在场 |

## 验收要点

- [ ] 导出 → 换浏览器导入（合并/覆盖两策略）→ 数据完整恢复（M1 验收演练 0 失败，需求 §1.5）
- [ ] 两个破坏性/替换性操作均有 ConfirmDialog 且按钮为动词（「清空数据」「替换数据」）
- [ ] 全页无「注册 / 登录 / 账号 / 云同步」字样
- [ ] 清空后各 key 删除、schemaVersion 保留，回游客态不白屏
