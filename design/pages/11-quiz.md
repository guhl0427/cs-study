# 11 · 测验作答 `/quiz/:id`

> 功能 F5（5.1/5.2）· P1 · 组件：QuizCard / ProgressTier(测验档) / Toast / 结果摘要卡
> 定位「自测工具」：答案随包下发是既定妥协（F5 说明），全站用「自测/练习」词，不用「考试/评分」。

## 目的

章节末随堂练习与课程综合测验的统一作答页：即时判分、即时解析、结果回写错题本。

## 布局（container-text 单列）

```
┌──────────────────────────────────────────────┐
│ AppHeader                                     │
├──────────────────────────────────────────────┤

│                                              │
│ ① 进度行：▓▓▓░░░ 第 3 / 8 题（mono）            │
```

## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |
| ---- | ---- | ---- | ---- |
| ① | 进度行 | ProgressTier 弱形态（细条）+ mono 计数 | 逐题推进，不可跳题（保持自测节奏） |
| ② | QuizCard | 题干 / 选项 / 提交 → 判分 / 解析 / 关联知识点 | 提交后写入 `cs-study:answers`（FIFO 500 条上限）；答错自动进错题本（F5.3） |
| ③ | 完成页 | 得分 + 薄弱知识点提示（错误题关联 lesson 去重）+ 三行动作 | 重做 = 仅重做本次答错题；文案「正确率」而非「分数」（弱考试感） |

## 词汇表

| 场景 | 用词 | 不用 |
| ---- | ---- | ---- |
| 入口按钮 | 练习 / 自测 | 测验考试 |
| 结果 | 正确率 {x}% | 得分 / 及格 |
| 错误 | 回答错误 | 答错扣分 |

## 验收要点

- [ ] 判分纯前端、即时；作答记录本地持久（刷新续答可接受，重答从第 1 题开始即可）
- [ ] 错题与作答记录随导出迁移（F5 说明 3）
- [ ] 全站无「考试/评分/及格」词汇
