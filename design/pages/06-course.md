# 06 · 课程详情 `/course/:slug`

> 功能 F3.2 · P0 · 组件：PageHeader / ProgressTier(课程档) / StatusChip / MetaMono / DifficultyBadge / MarkDoneButton(不在此页) / EmptyState
> 数据：课程 JSON（章节内嵌）+ 本地 `progress` 聚合

## 目的

课程页是「施工进度表」：讲清这门课教什么、需要什么底子，列出全部章节与知识点，并让本地进度一眼可见。

## 布局（桌面 ≥1024，container-text）

```
┌──────────────────────────────────────────────────┐
│ AppHeader                                         │
├──────────────────────────────────────────────────┤
│ ① PageHeader                                      │
│   {课程名} (h1) + DifficultyBadge                  │
│   课程一句话简介                                    │
│   适合人群：… · 前置要求：…（lesson/领域链接）        │
│   预计时长：{总时长} · {n} 章 · {m} 个知识点          │
│                                                  │
│ ② 课程进度条（有记录时）                            │
│   ▓▓▓▓▓░░░░░░ 42% · 已完成 {k}/{m}                 │
│   [继续学习：{下一未完成知识点}]（primary）           │
│                                                  │
│ ③ 章节目录（h2 · 章节卡片纵向堆叠）                  │
│ ┌──────────────────────────────────────────────┐ │
│ │ 第 1 章 · HTML5 语义化    {k}/{m} 已完成  1–2 周│ │
│ │ ┌──────────────────────────────────────────┐ │ │
│ │ │ ✓ 1.1 文档结构与常用标签    L1 · 30min    │ │ │
│ │ │ ◐ 1.2 表单与校验           L1 · 45min    │ │ │
│ │ │ ○ 1.3 多媒体与可访问性      L1 · 40min    │ │ │
│ │ └──────────────────────────────────────────┘ │ │
│ │ （章节末练习入口 · P1 起显示）                  │ │
│ └──────────────────────────────────────────────┘ │
│                                                  │
│ AppFooter                                         │
└──────────────────────────────────────────────────┘
```

## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |
| ---- | ---- | ---- | ---- |
| ① | PageHeader | 课程名 + 难度徽标 + 简介 + 适合人群 + 前置要求（可链接）+ MetaMono 总量行 | 前置要求链接 → 对应知识点/领域 |
| ② | 课程进度条 | ProgressTier 课程档；无记录时不渲染此块（③ 首章直接开始） | [继续学习] 定位到首个非已完成知识点；全完成 → 按钮变「复习第 1 章」+ 课程测验入口（P1） |
| ③ | 章节目录 | 章节卡：`第 {n} 章 · {章名} · {k}/{m} 已完成 · MetaMono 建议时长`；内嵌知识点行：`状态圈 + 序号.标题 + 难度 + 预计分钟` | 知识点行点击 → 知识点页；整行可点（非仅标题）；章节标题不可折叠（一屏全景优于折叠） |

**行内状态图例**：`✓ 已完成`(success) / `◐ 学习中`(teal) / `○ 未开始`(faint) —— 与 StatusChip 同语义，行内用符号版省空间。

## 响应式

- 知识点行在 `<640` 换两行（标题行 + meta 行）；进度条常驻可见。
- 章节卡内边距 `--space-4`（移动）→ `--space-5`（桌面）。

## 空状态

- 课程无章节（校验拦截，兜底）→ EmptyState。

## 验收要点

- [ ] 进度百分比 = 本地聚合（F4.2），刷新/回访一致
- [ ] 每个知识点行显示预计时长（与 frontmatter `est_minutes` 一致）
- [ ] 「继续学习」按钮定位正确（首个未完成，按章节内顺序）
- [ ] 前置要求缺失内容时显示为纯文本，不留死链
