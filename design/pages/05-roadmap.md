# 05 · 学习路线图 `/path/:slug`

> 功能 F2（2.1–2.6 全部）· P0 · 组件：PageHeader(图纸标题栏变体) / StageTrack / PathNode / BranchGroup / DependencyLine / RoadmapLegend / GridPaper
> 本页是全站视觉符号最重的一页——「学习地图」的图本体。

## 目的

把「先学什么后学什么」画成一张可执行的图：阶段、节点、依赖、分支、时长、状态，六种信息一次读全。

## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |

| ① | PageHeader | 路线名 + 描述 + 目标人群一行；图纸标题栏：阶段数 / 知识点数 / 总时长（各阶段建议时长求和）/ 版本 | 布局切换为 segmented（纵向默认；横向仅 lg 可用，md 以下隐藏切换） |

### 状态与依赖（F2.2 / F2.3）

- 节点状态三态 + 焦点环（当前推荐），见 components.md PathNode；状态来源 `progress`，回访不丢失。
- **前置未满足**：节点下方 `建议先完成：{前置名}`（`--warning`）；前置满足后消失。前置判断只做「提示」，**不阻断点击**（允许跳跃学习，但要知道代价）。
- 完成一个知识点回访本页：对应节点自动亮为已完成（「标记完成链」的第三环）。

### 进入定位

- 有学习记录时进入本页：滚动并短暂高亮「学习中」节点（320ms 焦点环脉冲一次，`prefers-reduced-motion` 下仅静态焦点环）。

## 响应式

- `<1024`：仅纵向模式；竖线轨道贴左，节点卡全宽可换行。
- `≥1024`：可切横向（阶段为泳道，横向滚动容器，图例 sticky 右上）。
- 375px：阶段头信息折行；节点 MetaMono 允许省略时长仅留难度。

## 空状态

- 路线数据缺失（构建期校验拦截，理论不出现）→ EmptyState。

## 验收要点

- [ ] 六种信息齐备：阶段/节点/依赖/分支/时长/状态（F2.1–2.6 逐条对照）
- [ ] 整图有文本替代（每阶段列表含前置说明，屏幕阅读器可读）
- [ ] 依赖提示不阻断跳转；分支「二选一」语义可见（虚线 + 标签）
- [ ] 布局切换不丢失滚动位置（纵向↔横向）
- [ ] 无力导向动画；进入定位动效单次播放
