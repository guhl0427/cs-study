# 08 · 个人中心 `/profile`

> 功能 F4 / F7（7.1–7.3）· P0 · 组件：ProfileIdentity / ContinueCard / ProgressTier(领域档×9) / HeatCalendar / StreakBadge / StorageNotice(常驻) / Tab(收藏) / EmptyState
> 本页是「本地学员」的家：所有数据本地读取，无任何网络请求。

## 目的

聚合呈现：我是谁（可选档案）→ 学到哪（继续学习）→ 学了多少（统计）→ 坚持多久（打卡）→ 攒了什么（收藏），并持续提醒「数据仅在本机」。

## 布局（桌面 ≥1024，container-wide 两列 2:1）

```
┌──────────────────────────────────────────────────────────────────┐
│ AppHeader                                                         │
├──────────────────────────────────────────────────────────────────┤
│ ① StorageNotice 常驻提示条（warning 底 + [导出备份]按钮）            │
│                                                                  │
│ ② 左列（主）                       │ ③ 右列（辅）                   │
│ ┌ PageHeader：个人中心 (h1)        │ ┌ ProfileIdentity 卡          ┐│
│ │ ContinueCard（上次学到/继续）     │ │ [emoji头像] 昵称(默认「同学」) ││
│ │ 学习统计（h2）· GridPaper         │ │ 学习起始日 2026-11-05        ││
│ │   三个大数字：知识点 {n} · 天 {m}  │ │ [编辑档案]（ghost）          ││
│ │   · 连续 {s} 天(StreakBadge)      │ ├ 当前路线卡 ─────────────────┤│
│ │   各领域进度：9 行 ProgressTier    │ │ {路线名} · S2 进行中          ││
│ │   领域名 ▓▓▓░ 42% （纵向条形列表）  │ │ [查看路线图]                 ││
│ │ 学习日历（h2）· HeatCalendar       │ ├ 快捷入口 ───────────────────┤│
```

## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |
| ---- | ---- | ---- | ---- |
| ① | StorageNotice 常驻条 | 「你的进度仅保存在本设备浏览器中」+ 导出按钮；学习 ≥7 天追加备份建议句（F4.7） | 导出 → /settings（或直接触发导出，二选一：本页选跳转） |
| ② | 继续学习 | ContinueCard 同首页组件 | 无记录 → EmptyState 弱形态（引导找方向/浏览领域） |
| ② | 学习统计 | 三大数字（累计完成知识点 / 累计学习天数 / 连续天数）+ 9 领域进度纵向条形列表（纯 SVG/CSS，按需轻量实现，不引入图表库） | 数字变化由本地数据推导（F4.2/4.5）；空数据 → 数字为 0 并保留骨架 |
| ② | 学习日历 | HeatCalendar 近一年（移动端切当月视图）；数据从 progress 推导 | 悬浮/点按显示当日明细；图例固定右下 |
| ② | 收藏 | Tab「课程 / 知识点」；条目卡：标题 + 所属领域 + 收藏时间 + [取消收藏] | 取消即时生效（乐观更新 + Toast）；空 → EmptyState「还没有收藏」 |
| ③ | ProfileIdentity | 昵称（空显示「同学」）+ emoji 头像（预设 8 选 1，弹出选择 popover）+ 起始日 | [编辑档案] → inline 编辑态（不跳页）；全可选项，不填不影响功能（F7.1） |
| ③ | 当前路线卡 | `activePathId` 对应路线名 + 当前阶段 + [查看路线图] | 无当前路线 → 「尚未选定路线」+ [去 找方向] |

## 响应式

- `<1024`：单列 = 提示条 → 身份卡 → 继续学习 → 统计 → 日历 → 收藏 → 快捷入口。
- 日历移动端为当月网格（7 列），左右滑动切月。
- 领域进度列表两行一组（名称 + 条 + 百分比）纵向堆叠。

## 空状态汇总（全部有出路，不许死寂）

| 空态 | 文案 | 行动 |
| ---- | ---- | ---- |
| 无学习记录 | 「还没有学习记录」 | [3 分钟找方向] / [浏览全部领域] |
| 无收藏 | 「还没有收藏，遇到想反复看的课程或知识点可以收藏」 | 去浏览 |
| 无当前路线 | 「尚未选定路线」 | [去 找方向] |

## 验收要点

- [ ] 页面零网络请求；刷新后数据一致（localStorage 单一来源推导）
- [ ] 「仅存本设备」常驻在场 + ≥7 天备份提醒触发正确
- [ ] 隐私模式：页面可浏览，数字为 0，警示条在场，不报错
- [ ] 统计图表为轻量 SVG/CSS 自绘（bundle 不引入完整图表库，需求 §6.2）
- [ ] 收藏取消即时生效且与 `favorites` 键同步
