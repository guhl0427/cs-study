# 10 · 搜索结果 `/search`

> 功能 F6（6.1/6.2）· P1 · 组件：SearchInput / Tab / 结果行卡 / EmptyState
> 索引：构建期生成静态 JSON（MiniSearch/FlexSearch 级），前端内存检索，无服务端（F6 说明）。

## 目的

按标题与摘要快速定位课程/知识点；支持按领域与难度过滤。

## 布局（container-text 单列）

```
┌──────────────────────────────────────────────┐
│ AppHeader                                     │
├──────────────────────────────────────────────┤
│ ① 大号 SearchInput（自动聚焦，占位承接路由 ?q=） │
│                                              │
│ ② 过滤行：领域 Tab（全部 | 9 领域）· 难度 Tab   │
│    （全部 | L1–L4）                            │
│                                              │
│ ③ 结果列表（分组或平铺，默认平铺）               │
│ ┌──────────────────────────────────────────┐ │
│ │ [知识点] Promise 与异步编程                │ │
│ │ 前端开发 › Vue 3 生态 › 第 2 章 (面包屑 mono)│ │
│ │ 摘要一行（命中词 <mark> 高亮）              │ │
│ │ L2 · est 45min                             │ │
│ └──────────────────────────────────────────┘ │
│   … 共 {n} 条 · 耗时 {ms} ms（mono，透明度弱）  │
│                                              │
│ AppFooter                                     │
└──────────────────────────────────────────────┘
```

## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |
| ---- | ---- | ---- | ---- |
| ① | 搜索框 | 回车/输入防抖 300ms 即时检索；⌘K / Ctrl+K 全局唤起并聚焦 | URL 同步 `?q=`（可分享/回退） |
| ② | 过滤行 | 领域 × 难度两组 FilterTabs，可组合 | 过滤即重查（内存索引，毫秒级） |
| ③ | 结果列表 | 类型标（知识点/课程/领域）+ 标题 + 面包屑 + 摘要（命中 `<mark>`）+ 难度/时长 | 点击 → 对应页；超过 50 条折叠「显示更多」 |
| — | 空结果 | EmptyState：「没有找到与“{q}”相关的内容」+ 建议（换关键词 / 去找方向 / 浏览全部领域） | — |

## 边界

- 正文级检索（F6.3 P2）暂不做，UI 预留「搜索范围：标题与摘要」说明行（避免用户误以为全文搜索）。
- 拼音容错（F6 可选）：命中时结果行标注「已按拼音匹配」弱提示。

## 验收要点

- [ ] 无网络请求；首页输入到出结果 < 100ms（内存索引）
- [ ] `?q=` 直达结果；浏览器前进后退不重复触发渲染
- [ ] 命中高亮不注入 HTML（构建索引时转义，防 XSS）
