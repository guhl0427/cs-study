# 04 · 领域详情 `/domain/:slug`

> 功能 F3.1 · P0 · 组件：PageHeader(图纸标题栏变体) / PathNode(路线入口卡复用) / FilterTabs / DomainCard(课程卡变体) / StorageNotice
> 数据：领域 JSON + 该领域课程列表（构建期按难度排序）

## 目的

领域是「一张学习地图的封面」：讲清这个方向是什么、谁适合、先修什么，并给出两条入口——路线图与课程列表。

## 布局（桌面 ≥1024）


## 区块明细

| # | 区块 | 内容 / 数据 | 交互与状态 |
| ---- | ---- | ---- | ---- |
| ① | PageHeader | icon(32px) + h1 领域名 + 简介；图纸标题栏四格：图别 / 课程数 / 难度跨度 / 版本·日期 | — |
| ② | 适用信息行 | 适合人群 / 前置知识（领域链接）/ 并行建议；均 `--text-secondary`，前置为链接 | 前置领域链接 → /domain/:slug |
| ③ | 路线图入口 | 路线列表（通常 1–2 条）：路线名 + StageTrack 缩略预览（仅结构感，不交互）+ [查看完整路线图] | 主 CTA → /path/:slug |
| ④ | 课程列表 | DomainCard 课程变体：title / summary / `{n} 个知识点 · 约 {h} 小时` / DifficultyBadge | FilterTabs 按 L1–L4 过滤（纯前端过滤，无网络）；空过滤结果 → 「该难度暂无课程」行 |
| ⑤ | 学习建议 | 领域 JSON `advice` 字段；无则不渲染 | — |

## 响应式

- 课程卡：lg 2 列 / md 2 列 / sm 1 列；路线预览横卡在 `<640` 隐藏缩略图（保留 CTA）。
- 图纸标题栏 `<640` 折为 2×2。

## 空状态

- 课程列表为空 → EmptyState「本领域课程筹备中」+ 路线图入口仍在（路线优先于课程）。

## 验收要点

- [ ] 领域 h1 唯一；icon 与 tokens §6 映射一致
- [ ] 前置知识链接可点且不循环跳自己
- [ ] 课程列表默认排序 = 难度升序（构建期保证，UI 不提供排序切换）
- [ ] 本页不渲染「标记完成」类进度控件（进度属于课程/知识点层级）
