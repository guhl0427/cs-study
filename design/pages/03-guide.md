# 03 · 「找方向」引导问答 `/guide`

> 功能 F1.2 · P0 · 组件：ChoiceCard / PageHeader / GridPaper / PathNode(结果页复用) / ConfirmDialog
> 问答逻辑与选项文案由需求 F1.2 固定：Q1 兴趣方向 → Q2 当前基础 → Q3 投入时间

## 目的

用 3 道题把「不知道学什么」变成「一条有名字的路线 + 一个起点知识点」，结果写入本地档案。

## 布局（问答态，桌面/移动同为单列 container-text）

```
┌──────────────────────────────────────────────┐
│ AppHeader                                     │
├──────────────────────────────────────────────┤
│ PageHeader：找方向 (h1) + 副文案「3 道题，约 1 分钟」│
│                                              │
│ GridPaper · 问答卡                             │
│ ┌──────────────────────────────────────────┐ │
│ │ 第 2 / 3 题 · 兴趣方向（mono 进度）         │ │
│ │ 你更想做哪类东西？(h2)                      │ │
│ │ ┌────────────────────────────────────┐   │ │
│ │ │ 做网站页面 · 前端开发                │   │ │
│ │ │ 可视化反馈强，就业方向之一           │   │ │
│ │ └────────────────────────────────────┘   │ │
│ │ （选项卡 × 5，纵向堆叠）                    │ │
│ │ ← 返回上一题（Q1 时不显示）                 │ │
│ └──────────────────────────────────────────┘ │
│ AppFooter                                     │
└──────────────────────────────────────────────┘
```

## 问答明细（选项文案固定，不得改写）

| 题 | 问题 | 选项（标题 · 一句解释） |
| ---- | ---- | ---- |
| Q1 | 你更想做哪类东西？ | 做网站页面（前端）/ 做系统与数据（后端）/ 数据与智能（AI）/ 打好基础（计算机基础）/ 还不确定 |
| Q2 | 你现在的基础？ | 完全零基础 / 会一点编程 / 修过专业课 |
| Q3 | 每周能投入多少时间？ | 5 小时以内 / 5–10 小时 / 10 小时以上 |

- 交互：单选点击即进下一题（`--dur-fast`）；返回保留已选；进度标注 mono「第 n / 3 题」。
- 「还不确定」选项存在：Q1 选它时 Q2/Q3 照常，结果倾向「计算机基础」并明示「建议先打基础」。

## 结果页（答题完成后替换问答卡，GridPaper）

```
┌──────────────────────────────────────────────┐
│ 推荐结果（图纸标题栏变体：匹配领域 / 推荐路线 / 起点）│
│ ┌ 推荐领域卡：领域 icon+名 + 一句为什么         ┐ │
│ │ 推荐路线：{path 名} · 预计 {总时长}           │ │
│ │ 起步知识点：{lesson 名}（PathNode now 态展示）│ │
│ │ 每周计划：{按 Q3 映射的一句建议}              │ │
│ └────────────────────────────────────────────┘ │
│ [按此路线开始学习]（primary，写 activePathId）    │
│ [重新测一测]（ghost，回到 Q1）                    │
│ 说明行：结果已保存在本机，可在个人中心查看或重测     │
└──────────────────────────────────────────────┘
```

- 每周计划映射：`<5h → 「按最少节奏走，别跳阶段」；5–10h → 「标准节奏，阶段内可并行」；>10h → 「可双线并行（如语言 + 计算机基础）」`。
- 持久化：`cs-study:guide`（answers / recommendedPathId / completedAt），个人中心可查看与重测（F1.2）。

## 响应式

- 单列天然适配；选项卡在 375px 保证标题与解释不折行重叠（解释允许换行）。
- 结果页 PathNode 卡最小宽 260px。

## 空状态与降级

- 匹配逻辑无命中（理论不可能，兜底）→ 推荐计算机基础 + 提示「先打基础，再回来重测」。

## 验收要点

- [ ] 三题选项文案与需求文档逐字一致
- [ ] 结果可复现：同答案重测输出一致（纯前端匹配表）
- [ ] 「按此路线开始学习」后 Header CTA 状态更新（出现「继续学习」语义）
- [ ] 隐私模式可完整走完问答，但结果标注「刷新后丢失」（StorageNotice 全局警示条在场）
